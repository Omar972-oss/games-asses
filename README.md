# proyecto-DOMINIO

Mi sitio es una pagina web de video juegos para ver el catalgo y una descripción
como tal de los juegos.

## Vista previa

https://github.com/Omar972-oss/games-asses

## Dominio y entidades


Contacto.php = Aqui esta la parte de inicio de seción del usuario como tal
Index.php = En esta parte esta la zona del interfaz como se ve como la estructura de la paina
producto-detalle.php = Aqui esta la otra pagina donde te dice el detalle del producto lo que viene
siendo su genero o tipo de juego que es
productos.php = Viene aquí el catalogo de los juegos todos los juegos que estan ahí
